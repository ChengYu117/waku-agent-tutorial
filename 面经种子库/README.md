# 2026 Agent × 团队记忆共享 真实面经种子库（Waku 适配版）

> **定位一句话说明白**：本目录同步了 **20 份 2026 年 5 月—11 月真实大厂与垂类团队一面至三面面经**（10 份 Agent 偏向 `A01`–`A10` + 10 份后端偏向 `B01`–`B10`），并已围绕 **`waku-agent`（Agent 核心运行时 + 跨 Agent 与团队记忆共享 + Always-on 轻状态机 + 双层评测闭环）** 重新梳理了考点权重、能力证据矩阵与训练入口 [asu-training-seed.md](asu-training-seed.md)。

## 一、与 Twenty 后端向版本的核心差异 & 事实边界

1. **同一套 2026 真实考题语料，完全不同的主战场**：
   - `agent/A01`–`A10` 与 `backend/B01`–`B10` 完整同步自共享的 2026 真实面经归档（其「一、真实面试题清单」与「二、考官意图与大白话逻辑链」为通用考场真题资产；原文件中第三节为此前针对 Twenty CRM 的项目映射，学习 Waku 时请统一以本文件和 [asu-training-seed.md](asu-training-seed.md) 中的 **Waku 证据与缺口矩阵** 为准）。
   - Twenty 偏重“企业级多租户后端 + Agent 外壳”；而 **Waku 是纯正的 Agent-Native 项目**，最大王牌恰恰补上了 Twenty 的核心缺口：**三层记忆架构、读写门控（Retrieval Gate / Slot Gate）、防污染整理（Consolidation）、跨 Agent / 团队记忆共享（Waku Memory + Team Homes + Company Brain）、无 MQ 轻量事件状态机（Always-on）以及 4,700+ 确定性断言与 LLM Judge 分离的评测门禁**。
2. **忠于代码、严守诚实边界**：
   - 明确区分 **本仓库开源代码（`waku/` 本地底座 + `hosted/` 托管编排）** 与 **外部托管记忆服务（`waku.one` / `api.waku.one/mcp` 闭源服务端）**——绝不把外部 Waku Memory 服务端的内部存储说成自己在本仓库写的。
   - 严格遵守 `docs/status.md` 的真实状态：Slack 公共应用、Team Homes、托管连接器等目前主要在本地 fake stub 与离线单测中验证，**绝不编造“已在生产服务上万团队”的虚假数据**。
   - 凡是 Waku 刻意不做的纯后端重基础设施（Kafka/Redis 集群、MySQL 分库分表、多 Agent 自主协作）均清晰标为 `无证据`，在后端交叉面中走“原理 + 场景设计骨架”坦诚作答。

## 四、`/asu-skills` 快速启动指南（Waku 专属）

1. **开启「AI Agent 核心与团队记忆架构」主力模拟面（推荐首选）**
   > `读取 面经种子库/asu-training-seed.md，按 Contract-1 和 immediate 反馈模式，执行 /interview grill 开始模拟面试，每次只问我一题。`
2. **开启「Agent 运行时 × 无 MQ 轻量可靠后端」交叉模拟面**
   > `读取 面经种子库/asu-training-seed.md，按 Contract-2 和 immediate 反馈模式，执行 /interview grill，重点追问无 MQ 事件状态机、HITL 确认后代码执行、MCP 权限与零密钥代理。`
3. **专项压力面：只压测 Waku 最容易被问穿的边界与架构取舍**
   > `读取 面经种子库/asu-training-seed.md 的高风险 Claim 清单和场景 1–4，用 /interview grill 对我进行 deferred 模式压力面，重点追问本地与托管记忆边界、团队隐私隔离、防记忆污染及真实缺口。`
4. **按课程复习对应考点**
   > 打开 [Waku 教程总入口](../tutorial.md)，按课核对源码和测试，再参考 [训练种子第八部分](asu-training-seed.md) 选择对应模拟面。
